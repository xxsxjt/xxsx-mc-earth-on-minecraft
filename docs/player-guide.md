# Earth on Minecraft 玩家入门流程

这个 mod 面向“不需要先学化学也能玩”的玩家。核心玩法是：挖到更真实的矿床和岩石，用机器一步步处理，最后仍然得到 MC 和其他 mod 熟悉的锭、宝石、红石、青金石等物品。

## 第一步：拿到手册

合成 `野外地质手册`：

```text
任意一块泥土
或任意木板
或任意石头
=> 野外地质手册
```

右键手册会打开分页界面，左侧切换章节，右侧查看路线说明。这个配方故意很便宜，因为它是新玩家的说明书，不应该变成解谜门槛。

空手右键任意处理机器会打开该机器 GUI。手持可处理材料右键机器，会直接处理 1 个材料并给出多种产物。机器界面里也有 `打开手册` 按钮，测试路线时不用退出界面重新找书。

如果不知道某个材料下一步去哪，直接把鼠标停在 Earth on Minecraft 物品上。tooltip 会显示：

```text
下一步：应该放入哪台机器
示例产出：第一条可用路线会得到什么
常见来源：这个材料通常从哪里来
```

装了 JEI 时，可以在 `Earth on Minecraft 工业处理` 分类里查全部路线。

## 本体和附属

本体当前只覆盖现实地球基础：地质、矿床、岩石、土壤、水文、现代工业、电力、基础设施、手册和 JEI 路线。

这些内容先不放进核心：

- 地球人附属：真实人物属性、体温、营养、疾病、食物保存和医疗系统。
- 修仙附属：灵气、灵根、丹药、法宝、洞天和境界。
- 魔法附属：魔力、元素、仪式、符文、炼金和魔法生态。
- 科幻附属：太空、高级能源、AI、纳米和超现实自动化。

这样做是为了让核心 jar 适合所有玩家和整合包；附属可以改变玩法压力或世界观，但必须可选。

## 基础流程

```text
矿石/矿床
-> 颚式破碎机
-> 碎块
-> 球磨机
-> 粉末
-> 筛分 / 磁选 / 浮选 / 浸出
-> 精矿
-> 焙烧 / 还原 / 电解 / 精馏 / 合成 / 聚合
-> 原版锭、宝石、红石等兼容产物
```

## 典型路线

快速索引：

```text
矿床/矿石方块 -> 颚式破碎机
矿物碎块 -> 球磨机
磁铁矿粉/赤铁矿粉 -> 磁选机
黄铜矿粉/金粉/红石矿物 -> 浮选槽
精矿 -> 焙烧炉 / 还原炉 / 电解槽
盐粉 -> 电解槽，进入氯碱工业
煤粉/煤焦油/煤气 -> 气体分离器 / 精馏塔 / 蒸汽裂解炉
硫粉/氨/甲醇/乙烯/氯化钾 -> 化学反应釜或合成塔
长石粉/云母粉/铝硅酸盐粉 -> 筛分机 / 工业窑炉
水泥粉/塑料树脂 -> 压粉机
```

铁：

```text
磁铁矿矿石 Fe3O4
-> 破碎机：磁铁矿碎块 + 尾粉
-> 球磨机：磁铁矿粉
-> 磁选机：铁精矿 + 尾粉
-> 还原炉（煤烧焦炭作装料）：海绵铁 + 矿渣
-> 石砧 + 地质锤：熟铁
-> 石砧 + 地质锤：minecraft:iron_ingot
```

首铁设备不需要先有铁：球磨机用石料和熔炉，磁选机用铜锭和磁铁矿碎块且可烧煤，简易还原炉用砖和熔炉。磁铁矿碎块和粉末不再能直接在原版熔炉或高炉里烧成铁锭。

铜：

```text
黄铜矿矿石 CuFeS2
-> 破碎机：黄铜矿碎块 + 黄铁矿粉
-> 球磨机：黄铜矿粉
-> 浮选槽：铜精矿 + 黄铁矿粉 + 尾粉
-> 焙烧炉：焙烧铜精矿 + 硫粉
-> 还原炉/电解槽：minecraft:copper_ingot + 副产物
```

金：

```text
含金石英脉
-> 破碎机：含金石英碎块 + 石英粉
-> 筛分机/浸出槽：金粉或金精矿 + 二氧化硅粉 + 尾粉
-> 还原炉/电解槽：minecraft:gold_ingot
```

钻石：

```text
含金刚石金伯利岩
-> 破碎机：金伯利岩碎块 + 金刚石砂粒
-> 筛分机：更多金刚石砂粒
-> 压粉机：minecraft:diamond
```

## 岩石不是单一化学式

原版花岗岩、闪长岩、安山岩、深板岩、凝灰岩、方解石、滴水石、砂岩、黑石、玄武岩等都被视为混合岩石。它们不会假装只有一个化学式，而是通过球磨产出多种粉末。

普通石头和圆石要单独理解：普通石头是 MC 对“本地未分类地层石料”的泛化表达，不等于花岗岩；圆石是破碎后的本地石料骨料和采石粉尘，也不是独立天然岩石。

例子：

```text
花岗岩
-> 球磨机
-> 石英粉 + 长石粉 + 云母粉 + 尾粉
```

现实世界不能简单磨一块石头就得到 100% 纯物质；Earth on Minecraft 的折中是：处理路线尽量真实，但最终允许 MC 世界用机器/合成魔法整理成可堆叠、可合成的物品。

## 自动化采矿

矿床不是无限的。每一处矿脉都有储量，采空之后会变成贫矿块，外观和掉落都变差。

```text
工业钻采头（bore_head）
-> 扫描周围 24 格的矿脉
-> 消耗 EOU 抽取矿石，直接进 9 格输出箱
-> 矿脉采空后自动换成贫矿块

采石场（quarry）
-> 扫描机器下方 2～3 层的 5×5 工作区，保留紧贴机器的支撑层
-> 普通岩石按实际方块掉落并移除；遇到活动矿床时按有限储量抽取
-> 活动矿床采空后留下采空围岩，下一次作业再移除采空方块
-> 40 tick / 12 EOU 一份，比钻采头慢但更便宜
```

两者都需要现实支撑规则：要么底下有实心方块，要么贴着墙或相邻基础设施，否则不工作。输出箱可以被传送带或漏斗直接抽走。矿体扫描仪右键会报告以玩家为中心、半径 24 格球形范围内仍有储量的矿床，不会修改地形。

右键钻采头可以看当前可采储量、已存物品和追踪的矿脉数量；右键矿脉本体可以看剩余 / 总容量。

## 农业与草药

草药和作物在原 spec 里只有 `gather:wild_herb`、`agriculture:crop` 这类占位来源，没有任何实际产出。现在有两条路：

```text
野生采集
-> 打草、蕨、大蕨，12.5% 概率掉一株随机草药

繁殖（药草处理台）
-> 1 株草药 + 1 份骨粉或钾盐
-> 2 株同种草药

作物（药草处理台 / 木工台 / 熏制房）
-> 种子作物：1 份 + 骨粉 -> 2 份
-> 果树：木材梁 + 钾盐 -> 果实
-> 畜产：干草 + 麸皮 -> 蛋、奶、蜂蜜等
```

草药按目录分节对应到不同植物：木本和树脂类走骨粉，矿物类（明矾、硼砂、朱砂等）走钾盐。

## 饮料与药品

```text
饮料（83 条路线）
咖啡：生豆 -> 咖啡烘焙机 -> 研磨 -> 冲泡
茶：鲜叶 -> 茶炒锅 -> 揉捻 -> 干燥
```

药品链严格只用 spec 里真实存在的材料：水杨酸、苯酚、甲苯、葡萄糖这些中间体都在，虚构的血清、鸦片乳之类没有。

## 聚落与居民

1. 用木板和纸合成聚落公告板，并放在村庄、矿业工坊或机器区附近。
2. 右键公告板查看聚落产业、当前需求、可供应物资、实名居民和已登记设施。
3. 潜行右键居民可查看姓名、现实工作角色、所属聚落和熟练度。
4. 矿工、地质调查员、机修工、电工、水务操作员和仓库管理员会根据原版职业与聚落类型分配，并保留原版交易兼容性。
5. 角色专属交易会混入对应原版职业的等级交易池；JEI 搜索“聚落公告板”可查看入口说明，手册“聚落”页提供玩法解释。
6. 安装魔幻地球或玄幻地球后，公告板会识别其聚落锚点，显示对应聚落档案、居民和设施；这些附属聚落的工作站与储物桶也会计入公告板。
