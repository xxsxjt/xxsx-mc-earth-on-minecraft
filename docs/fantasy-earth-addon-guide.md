# 魔幻地球（Fantasy Earth）本体联动指示

本文面向 `fantasy_earth` 的后续实现与验收。以本体当前 `0.1.16` 代码和生态契约 v1 为准；不要把旧版本记录当作当前接口。

## 目标与边界

- 魔幻地球保持独立可玩：无本体时，手册、启蒙、调律、炼金、符文、仪式、法术、魔幻材料和生物仍有完整原版/自身材料回退路线。
- 本体只提供现实材料、地质、能源、机器、物流和可选世界/聚落接口；魔力、以太场、魔幻进度、法术和魔幻居民归魔幻地球所有。
- 不把超自然矿物、仪式或魔法状态写入本体；不跨仓库导入本体 Java 类，不改写本体配方或注册表。
- 魔幻以太场、符文与仪式语义不得被玄幻灵气代替；两条路线可以共用法力值，但不共用环境场、进度树或玩法表现。

## 本体当前可消费接口

### 标签

数据配方和设施优先读取本体的物品标签，保持 `replace: false`，由魔幻地球自己的标签为本体缺席时追加原版/本模组回退材料：

- `#earth_on_minecraft:arcana_geology_catalysts`：石英、辰砂、金、稀土和锂等地质催化材料。
- `#earth_on_minecraft:aether_crystal_substrates`：锂盐、独居石砂、混合稀土氧化物、钕盐、陶瓷基板等以太/晶体基材。
- `#earth_on_minecraft:mana_conductors`：铜线、铜母排、覆铜板、PCB 与稀土磁材等导能材料。
- `#earth_on_minecraft:electrical/conductors`、`#earth_on_minecraft:electrical/insulators`、`#earth_on_minecraft:power/connectors`：需要与本体电气设备协作时使用；它们描述现实电气角色，不自动代表魔力属性。
- `#earth_on_minecraft:construction/materials`、`#earth_on_minecraft:filtration/media`：用于仪式场地、设施或过滤媒介时按实际语义选用。

配方可用 NeoForge `mod_loaded` 条件保护本体标签配方。标签为空或本体缺席时，不报错、不锁死进度；JEI 隐藏不可用增强配方，同时保留独立回退配方。不要把电力导体标签直接等同于 mana conductor。

### 稳定数据与查询

- 共享法力数据采用 `earth_arcana.*`。本体不拥有也不写这些键；魔幻只写 `magic_*`、魔幻研究/调律与奥术专用键，只增加 `magic_mana_bonus`，不得重置或覆盖玄幻分项。
- `earth_online_arcana.*` 仅是一次性旧数据迁移输入；迁移必须幂等，现行写入使用 `earth_arcana.*`。
- 本体公开 `EarthOnMinecraftApi v1`：材料属性、地质查询、机器/路线、能源、物流和聚落查询。需要运行时信息时才使用 API；材料配方优先标签。通过可选依赖或隔离的反射适配器检测 API，缺失、版本不符或调用失败均安全降级。
- 可选聚落锚点为 `fantasy_earth:settlement_anchor`；本体当前识别魔幻锚点、魔幻设施和居民，并使用 `earth_on_minecraft:arcane_settlement` 档案。锚点/板/居民交互属于组合安装能力，须在兼容版本的集成测试中验证。

## 按当前魔幻地球状态推进

魔幻地球仓库当前目标为 MC 26.2 / NeoForge 26.2.0.7-beta、`fantasy_earth` 0.7.0-alpha.10；已有独立手册与启蒙流程、区块级以太场、炼金/符文/仪式设施、JEI、法力消费、主动法术、熟悉生物和魔幻聚落。后续工作按下列顺序接入本体：

1. **确认版本线**：本体 0.1.16 当前针对 MC 26.1.2 / NeoForge 26.1.2.124；魔幻地球当前是 MC 26.2。二者不是可直接组合的运行目标。不得因 `modId` 或标签名相同就宣称兼容，也不要把 26.1.2 本体 JAR 放入 26.2 附属测试实例。先选定同一 MC/NeoForge 版本并构建本体与附属候选件。
2. **材料接入**：盘点炼金、符文、仪式配方；对本体能提供的现实催化剂/导体使用上述标签，避免硬编码具体矿物 ID。保留紫水晶、原版红石及魔幻自有材料回退。
3. **领域化机器**：现实工业机器只作为可选前处理或现实材料来源。魔幻的仪式/炼金结果仍由魔幻设施和魔幻配方产出；不得要求本体处理机才能完成独立魔幻主线。
4. **法力与人体**：执行共享法力分项所有权；与 `earth_human` 的恢复只能走其公开 API，缺失时关闭人体增强，不读写对方私有 NBT。若玄幻也在场，由契约规定的单一所有者负责共享身体效果和玩家数据复制，防止双重结算。
5. **聚落**：保留魔幻地球的聚落生成、锚点与居民；可选登记到本体板/档案。锚点缺失或本体未装时，魔幻聚落仍须正常生成和游玩。
6. **玩家说明**：手册和 JEI 清楚标注“本体材料增强（可选）”、缺少本体时的回退路线、魔力与玄幻灵力共享法力但来源不同。

## 验收门槛

- 魔幻地球单装：无其他生态模组仍能新建世界并完成独立启蒙、调律、设施产物、法术、恢复和熟悉生物闭环。
- 本体 + 魔幻：在同一 MC/NeoForge 版本上验证标签非空、增强配方可用、JEI 输入/输出和本体缺席回退；不以资源加载成功代替配方可用。
- 魔幻 + 玄幻 + 本体：共享法力上限等于基础值、两侧路线贡献、装备贡献和临时贡献之和；分别升级一侧不得清除另一侧数据；身体效果与重生复制只结算一次。
- 本体版本更新：验证本体标签成员变化、可选 API 版本、锚点/居民/聚落档案；未知 ID 或缺失依赖应安全降级。
- 发布说明分别记录目标版本、构建、独立测试、组合测试和未验证项；未做客户端/服务器集成测试时不得写“联动已验证”。

## 当前明确未证实

本体 0.1.16 与当前魔幻地球 0.7.0-alpha.10 的跨版本组合尚未验证；标签配方/Java 可选适配器在双方同时运行时的 JEI、客户端、服务器与世界数据表现，也须在统一版本构建后实测。
