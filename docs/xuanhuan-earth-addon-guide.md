# 玄幻地球（Xuanhuan Earth）本体联动指示

本文面向 `xuanhuan_earth` 的后续实现与验收。以本体当前 `0.1.16` 代码和生态契约 v1 为准；旧契约版本号和旧构建记录只作历史参考。

## 目标与边界

- 玄幻地球保持独立可玩：无本体时仍能发现灵性异常、采集玄幻资源、修炼、使用丹炉/符案/阵法、施展功法并完成独立成长闭环。
- 本体负责现实岩性、矿床、土壤、水文、工业、能源和物流；玄幻地球负责灵气、灵脉、灵泉、灵植、阵法、丹药、符箓、法器和玄幻成长。
- 不把灵气、修为、玄幻矿物或阵法写入本体；不跨仓库导入本体 Java 类，不覆盖本体方块、配方或世界生成。
- 现实地质只能为玄幻内容提供有因果的环境和材料基础；它不能取代玄幻专属灵气场，也不能让本体成为玄幻玩法的强制前置。

## 本体当前可消费接口

### 标签

配方通过本体标签识别材料角色，而非枚举本体物品 ID。玄幻侧追加回退材料时使用 `replace: false`：

- `#earth_on_minecraft:spiritual_mineral_substrates`：含金石英碎块、石英/硅石粉、辰砂/金粉及稀土尾料等灵性矿物基材。
- `#earth_on_minecraft:arcana_geology_catalysts`：石英、辰砂、金、稀土氧化物、钕盐、锂盐和钕铁硼等地质/超凡催化材料。
- `#earth_on_minecraft:mana_conductors`：铜线、铜母排、覆铜板、PCB、钕铁硼和稀土材料等导能材料。
- `#earth_on_minecraft:electrical/conductors`、`#earth_on_minecraft:electrical/insulators`、`#earth_on_minecraft:construction/materials`、`#earth_on_minecraft:water/treated`：仅在玄幻机制确实消费电气、建造或水处理角色时使用；不要把它们解释为灵气标签。

本体缺席时，增强配方由 `mod_loaded` 条件关闭，原版/玄幻自有配方继续可用；标签空时隐藏不可用增强路线并提供可理解的提示，不能让存档或资源重载失败。

### 稳定数据与查询

- 共享法力数据采用 `earth_arcana.*`。玄幻只写 `xuanhuan_*`、修行等级/经验、吸收率与玄幻专用键，只增加 `xuanhuan_mana_bonus`；不得覆盖 `magic_mana_bonus` 或清除魔幻进度。
- `earth_online_arcana.*` 仅作为一次性兼容迁移来源；迁移幂等，现行状态写到 `earth_arcana.*`。
- `EarthOnMinecraftApi v1` 可查询本体材料性质、地质样本、机器路线、能源、物流和聚落。不要把 API 当成世界场模拟：灵气来源、区块状态、修炼收益由玄幻地球持有。
- 本体识别可选锚点 `xuanhuan_earth:settlement_anchor`，并提供 `earth_on_minecraft:cultivation_settlement` 档案及玄幻居民角色映射。组合安装时可把玄幻设施/聚落接入本体板；本体缺失时玄幻锚点和聚落仍独立工作。

## 按当前玄幻地球状态推进

玄幻地球仓库当前目标为 MC 26.2 / NeoForge 26.2.0.7-beta、`xuanhuan_earth` 0.7.0-alpha.8；已有独立手册、引气诀和多路线成长、区块灵气场、灵脉/灵泉/灵土/阵法、丹炉/符案、主动功法、灵兽和玄幻聚落。当前分支还在推进法术图谱、灵石/符箓充能与场域账本；联动实现不得绕开这些权属边界：

1. **确认版本线**：本体 0.1.16 当前针对 MC 26.1.2 / NeoForge 26.1.2.124；玄幻地球当前是 MC 26.2。须先统一目标版本并构建对应本体和玄幻 JAR；不得把不同 MC/NeoForge 版本的产物混装或将“可选依赖”误当跨版本兼容。
2. **接地质、不接管灵气**：可用矿物/岩性/水文材料标签改善灵墨、丹材、阵基或导能器配方；灵脉生成、灵泉、灵土、区块 qi、枯竭和修炼结果仍由玄幻地球实现。
3. **材料来源可解释**：优先把本体真实材料接在玄幻专用加工前段，随后由玄幻丹炉、符案、阵法或专用配方完成超凡转化。不要让普通磁选、化学反应器或本体电网直接产出灵气/修为。
4. **共享法力所有权**：基础法力、玄幻贡献、魔幻贡献、装备贡献与临时贡献按契约相加。玄幻只写自身贡献；魔幻可缺席。玄幻与魔幻并装时，由契约指定的唯一模块处理共享身体效果和玩家数据克隆，禁止重复回血、减耗、抗伤或重生复制。
5. **人体可选联动**：与 `earth_human` 只通过其公开 API/共享契约联动。API 缺失或版本不符时关闭人体增强，修炼主线照常运行；不得读写 `earth_human.*` 私有状态。
6. **聚落可选登记**：锚点可以绑定本体聚落档案和居民板，但玄幻自己的灵泉村、宗门前哨、游商聚落与居民生成仍由玄幻地球管理；安装组合失败时不得破坏原版村庄或停止玄幻聚落。
7. **保持中文玄幻语义**：手册区分灵气场、法力总值、玄幻路线贡献与魔幻路线贡献。共享的是玩家可用法力，不是 qi 与 aether 场、修炼等级或法术树。

## 验收门槛

- 玄幻单装：无本体、魔幻或地球人时，独立世界、手册、引气/修炼、玄幻设施和成长闭环均可用。
- 本体 + 玄幻：同版本下验证现实材料标签和增强配方、JEI 显示、回退路径、地质/聚落查询及锚点行为；实际配方产出须与标签成员和加工流程相符。
- 玄幻 + 魔幻 + 本体：交替学习/升级两条路线，验证分项相加、法力消费/恢复、存档迁移和身体效果单次结算；移除任一可选模块后剩余模块安全加载。
- 场域隔离：本体岩性/矿床可按设计调整灵气来源权重，但普通工业耗能、机器运行和电气导体本身不应无意改变 qi；玄幻灵脉/阵法也不应改写本体材料数据。
- 资源与版本：标签空、材料 ID 未注册、API 缺失、未知 Arcana 键或可选模组缺席时安全降级；在实际 MC/NeoForge 版本上分别做单装及组合启动/数据重载测试。
- 发布记录明确区分源码/静态检查、单模构建、组合构建、服务端/客户端运行与游戏内验证，不以编译成功声称联动实测通过。

## 当前明确未证实

本体 0.1.16 与当前玄幻地球 0.7.0-alpha.8 的跨版本组合尚未验证；灵石、符箓充能/账本等进行中实现与本体标签、Arcana 分项及聚落锚点的最终组合行为，也须在同版本组合实例中验证。
