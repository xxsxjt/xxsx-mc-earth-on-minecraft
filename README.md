## 核心定位：为什么是硬核地球底座？

`The Earth / 地球` 不是简单的“加几个矿石和机器”的科技模组，而是 **Earth Series（地球系列）的核心物质与物理法则底座**。我们在保留 Minecraft 原版成品兼容性的前提下，彻底重写了从地壳矿床到现代重工业的底层因果律：

1. **原版矿石彻底禁用 × 真实地质与矿物化学式**
   - 彻底移除主世界原版自然矿石生成与 `ore_veininess` 巨型矿脉噪声，杜绝“挖一块铁矿烧一块铁锭”。
   - 替换为 **37 类有限真实矿床**与地层/围岩伴生体系（沉积砂岩/石灰岩、花岗闪长质侵入体、安山凝灰火山带、玄武质岩脉），矿物严格遵循真实化学式与脉石品位：磁铁矿 `Fe3O4`、赤铁矿 `Fe2O3`、黄铜矿 `CuFeS2`、方解石 `CaCO3`、方铅矿 `PbS`、闪锌矿 `ZnS`、铝土矿、独居石、蒸发岩盐层、油气藏等。
2. **成分纯度冶金 × 多输入化学计量全产业链**
   - **铁钢演进闭环**：从原始块铁炉（Bloomery）还原出含渣海绵铁块（Sponge Iron Bloom），经锻打除渣得到熟铁/锻铁，再到竖炉生铁、碱性氧气转炉吹炼钢坯与特种合金钢。
   - **全流程选矿与化工**：涵盖破碎、球磨、筛分、磁选、泡沫浮选、氧化焙烧、碳热/气体还原、酸碱浸出、水溶液/熔盐电解、多级精馏、管式蒸汽裂解、催化合成与高压聚合，辅料熔剂、尾矿与炉渣全部纳入物质守恒闭环。
3. **真实四阶段动力演进 × 开尔文（K）热工学**
   - **拒绝无人假自动运转**：废除“无动力自动兜底”。
   - **人力（MANUAL）**：手工作业台与原始设备必须由玩家在界面点击步进或潜行右键实操驱动，无人操作即停机等待。
   - **机械动力（KINETIC）**：磨机、筛机等机械设备必须检测水轮水利、高空风车或传动机构输入，否则处于机械待机。
   - **热力（THERMAL）与开尔文温标**：实装基于开尔文（`K`，常温 `293 K`）的真实炉温升降曲线与燃料理论最高温上限——木屑/海带仅达 `900 K`、煤粉 `1400 K`、原煤/木炭 `1550 K`、煤气/天然气 `1750 K`、冶金焦/石油焦/熔岩可达 `2100 K`。炉温未达到当前机器与配方的目标阈值（`Target K`）前只进行预热，绝不推进加工进度；燃料热值不足时直接触发燃料温度上限告警。
   - **电力（ELECTRIC）**：现代重工业与电解/裂解/高压合成设备接入 **EOU 电网** 与机载电容缓冲，按实时功率消耗运行。
4. **严格 3D 层级多方块蓝图 × 坐标级结构诊断 × 工业级 GUI**
   - 废除粗放的范围凑数判定：6 座传统砌筑窑炉（土坑窑、面包窑、石灰窑、块铁炉、玻璃窑、竖炉）与 8 类现代工业多方块（精馏塔、管式蒸汽裂解炉、浮选槽、反应釜、电解槽列、焙烧/还原热工线、加压撬块、高压合成回路）全部采用严格朝向对齐的 **3D 逐层结构蓝图（含内部腔体空气校验）**。
   - **精确到坐标的故障诊断**：右键未成型的控制面板或结构件，立即刷新全息投影并精确指出**具体哪个世界坐标 `(x, y, z)` / 相对控制器偏移 `(+dx, +dy, +dz)` 缺少什么部件或放错了什么方块**，以及当前完成度（`已就位/总数`）。
   - **直观工业 GUI**：内置实时开尔文温度计与目标温标线、EOU 电容电量条、手动步进操作钮、实时遥测底栏（`温度 K / 电量 EOU / 配方耗时`）与六面 IO 展开页，一切运行阻塞原因一目了然。
5. **Earth Series 核心底座：支撑人类生存、玄幻、魔幻与科幻附属**
   - 作为整个地球系列的底层基石，本体提供版本化地质、材料、热工、能源、物流与聚落 API（`v1`）以及跨模块材料标签契约：
     - 向上支撑 **《Earth Human》** 的现实人体生理、温湿度与环境生存接口；
     - 为 **《Earth Online: Magic（魔幻）》** 与 **《地球 Online：玄幻》** 提供真实的矿物伴生灵材/魔导基底、炉温丹火/锻造耦合与共享持久化契约；
     - 为未来的 **科幻/太空扩展** 奠定核燃料循环（独居石 → 黄饼 → `UF6` → `UO2` 燃料组件）、半导体多晶硅晶圆、钛合金、稀土永磁与 PLC 自动化工业底座。
   - 完整边界见 [现实仿真原则](docs/reality-simulation-principles.md) 与 [四模块生态联动契约 v1](docs/ecosystem-integration-contract-v1.md)。

> 保留 MC 的物品生态和合成魔法，但把自然来源、物质流程、工具使用、空间关系和基础设施因果尽量真实化。

这个项目的目标不是把 Minecraft 变成纯现实模拟器，而是建立一个有现实因果的地球内容层：原版锭、宝石和合成体系尽量保留，矿石、岩石、工具、建筑、能源、运输、测量和工业流程改成更符合现实直觉的系统。现实规则优先于 Minecraft 的默认便利；例如普通方块不能凭空悬浮，工具不能隔空完成不具备接触和支撑条件的工作。完整边界见 [现实仿真原则](docs/reality-simulation-principles.md)。

## 第一版目标

- 移除原版自然矿物生成，用真实矿床替代。
- 保留 `minecraft:iron_ingot`、`minecraft:copper_ingot`、`minecraft:gold_ingot` 等原版成品，保证其他 mod 兼容。
- 岩石按混合物处理，显示主要矿物组成和比例。
- 矿物按化学式处理，例如磁铁矿 `Fe3O4`、黄铜矿 `CuFeS2`、方解石 `CaCO3`。
- 处理流程遵循现实思路：破碎、磨粉、筛分、磁选、浮选、焙烧、还原、电解、精馏、吸收、合成、裂解、聚合。
- MC 世界允许最终获得纯净粉末/锭/块，用来降低背包和自动化复杂度。

## 本体与附属边界

本体只做现实地球的自然来源、物质流、工业、电力、物流、基础设施、手册和 JEI 路线。核动力、电网、PLC、传感器、输送和现代自动化属于本体；人物属性、食物保存、修仙、魔法、太空、AI 自治社会、纳米制造、反物质和曲率等属于独立路线或未来附属。

新增内容优先保证本体可玩、可查、可兼容：玩家看到一个材料时，tooltip、机器界面、手册和 JEI 都应该告诉他下一步做什么。

## 可选模块生态

本体、`Earth Human`、`Earth Online: Magic` 和 `地球 Online：玄幻` 是可独立安装的同一生态。拆分用于并行开发和玩家自由选装，不代表互不联动：本体发布材料与环境角色标签，Human 消费现实环境接口，Magic/玄幻消费本体材料并通过共享持久化键协作。任何缺失组合都必须正常启动，详细规则见 [联动契约 v1](docs/ecosystem-integration-contract-v1.md)。

## 本地验证

```powershell
cd neoforge-26.2
.\gradlew.bat compileJava verifyStaticQuality jar --console=plain
cd ..
pwsh -NoProfile -File tools\render_gui_previews.ps1
python tools\render_connected_ore_previews.py
```

构建需要 JDK 25；通过本机 `JAVA_HOME` 指向安装目录，或在 Gradle 命令中传入 `-Porg.gradle.java.installations.paths=<JDK目录>`。JEI 编译 API 由 Maven 获取。上述静态验证不会启动 Minecraft；`build` / `check` 还会运行 GameTest，需单独执行。

连接矿床资源由 `tools/generate_connected_ore_assets.py` 统一生成；固定形状矩阵和全部矿床 2x2 联系表输出到 `output/connected-ore-previews/`，用于贴图重做后的视觉回归检查。
